# Security policy

Rellane is an early source release and does not have a published support or patch timeline.

Please report a suspected vulnerability privately through GitHub's vulnerability reporting for this repository if available. Include a reproduction with synthetic data, the affected revision, and the impact. Do not post credentials, customer data, or working exploit details in a public issue.

Security reports will be triaged by the primary maintainer. Public fixes and advisories will follow verification of the affected path.
