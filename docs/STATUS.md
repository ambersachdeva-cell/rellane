# Project status

This repository is an early public source snapshot from committed revision `840c2c8` (16 September 2026). It has not been accepted as a general release. The source contains many implemented modules and tests; source presence and passing unit tests do not establish that an entire workflow is usable in the installed app.

The current public snapshot includes the desktop shell, local data and document code, model runtime integration, automation code, and synthetic tests. Work on reviewed graph execution, whole-workspace recovery, and other planned capabilities is still in progress outside this snapshot.

There are no established public adoption metrics or published downloads for this new repository. Contributors should report observed behavior against a specific revision and macOS version.
